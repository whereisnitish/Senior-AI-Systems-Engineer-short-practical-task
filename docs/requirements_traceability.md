# Requirements traceability

Independent pre-submission review, 2026-10-17. Every row was checked against the code and the test suite
(`python -m pytest -q`: **245 passed, 0 failed**; `ruff check`: clean) and, where it exists, the live
database `data/live.db` and the files in `reports/live/`.

**Status vocabulary.** *Implemented and tested*: code exists and an automated test exercises it.
*Implemented but unverified*: code exists, no test or run proves it. *Simulated*: exercised only against a
simulated transport, fake class or synthetic data. *Blocked*: cannot be done until missing access exists.
*Not implemented*: no code, or, in the live-run rows, **not yet performed**.

Test references are `file::test_name` under `tests/`. "Live" means the candidate-provided test
environment (`ENVIRONMENT_LABEL=candidate_provided_test_environment`).
